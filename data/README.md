# Generated data

Files here are **generated at build time and committed**, so that the published packages carry the
data they need without a runtime dependency.

## `banks.generated.json`

Nigerian bank reference data, generated from
[naija-data](https://github.com/asgatcreation/naija-data) and keyed by CBN/NIBSS bank code. Each
entry also records every provider-specific slug we have seen for that bank — `titan-paystack`,
`habari`, `wema`, `moniepoint` and so on — so a provider's own identifier can be mapped in both
directions without guessing.

Generated by `npm run build:banks` (milestone 3). Do not edit by hand.

**The build fails** if a provider's published bank list contains a bank that cannot be mapped to a
CBN/NIBSS code. The failure names the unmapped banks, which makes it a naija-data issue to fix rather
than a silent gap in the SDK. Reporting banks that cannot be mapped is a feature, not an obstacle.
