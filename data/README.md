# Generated data

Files here are **generated at build time and committed**, so the published packages carry the data
they need without a runtime dependency on naija-data.

## `banks.generated.json`

Generated by `npm run build:banks` from
[naija-data](https://github.com/asgatcreation/naija-data)'s `data/banks.csv`. **Do not edit by hand.**

naija-data's dataset is licensed **CC BY 4.0**. The attribution it requires is embedded in the
generated file's `source` block and must stay there.

### What this file is, and what it is not

It is an **institution registry used for enrichment**. It is _not_ a lookup table of codes to send to
providers.

Measured on 2026-10-26, from 899 institutions in the source:

|                                                  |       |
| ------------------------------------------------ | ----- |
| Kept (active or merged)                          | 898   |
| With a NIBSS NIP code                            | 49    |
| With a CBN code                                  | 141   |
| With a code naija-data could not verify upstream | 165   |
| Minified size                                    | 91 KB |

Institutions whose licence was revoked, or which are defunct, are dropped — nobody can be paid at
one. **Merged** institutions are kept deliberately, because providers still return their old codes
and a caller deserves to be told that the bank they are about to pay has been absorbed into another.

### Why it is not a code table

Only 49 of 898 institutions have a NIP code, while a provider like Paystack returns 292 Nigerian
banks under codes of its own, mixing 3, 5 and 6 digit forms. There is no universal code to normalise
onto.

So the rule, which is a money-safety rule and not a preference: **the provider's own bank code is
authoritative for calling that provider, and naija-pay never substitutes it.** This file supplies the
canonical institution identity, name, type, merger status and whatever NIP/CBN codes are known, so
that the same institution can be recognised across providers and so that weak or unverified data is
visible instead of assumed. See the bank-codes section of [DESIGN.md](../DESIGN.md) for the full
reasoning.

### Coverage

`npm run report:banks` shows how many of each provider's banks can be matched to an institution, and
lists the ones that cannot. Unmatched banks are a naija-data issue to fix, not a reason to block a
build — CI fails only if coverage regresses below the committed baseline.
