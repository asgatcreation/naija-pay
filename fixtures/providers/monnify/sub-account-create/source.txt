A settlement sub-account for split payments. The request body is an ARRAY and so is the
response, even for a single sub-account.

defaultSplitPercentage is a PERCENTAGE: 20 means 20%. naija-pay's API is basis points, so
2000 basis points becomes 20 here, and a share that cannot be expressed in whole basis
points is refused rather than rounded.

Live use of this API needs approval from a Monnify relationship manager, which is why the
capability is declared requiresApproval.
