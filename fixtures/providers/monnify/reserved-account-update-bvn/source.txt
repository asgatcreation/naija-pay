Setting a BVN on an existing reserved account. The BVN alone: this route takes no NIN.

The kyc-info route is a DIFFERENT endpoint that requires both a bvn and a nin, so the two
are separate methods on the adapter rather than one with optional arguments. Note also
that this route names its path parameter reservedAccountReference while its neighbours
call the same value accountReference.
